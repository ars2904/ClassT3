# 🎓 Complete 3-in-1 Tuition & Coaching Website Template Suite
> **Sell to ANY client:** From solo neighborhood tutors to 2–4 teacher coaching centers, up to multi-branch premier academies!

Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

---

## 🔄 Live Interactive Demo Switcher
At the top of the screen on any page, there is a floating pill:
> `Previewing: [Tier 1: Solo Tutor] | [Tier 2: Pro Growth] | [Tier 3: Elite Academy]`

This allows you to open your laptop or send a link to any potential client and let them see **all 3 packages live** before choosing which one fits their budget.

## ⚡ How to White-Label for Clients in 5 Minutes

### To customize Tier 1 (Solo Tutor):
Edit [`src/data/solo-tutor.ts`](file:///c:/Users/aryan/Classes-Template/src/data/solo-tutor.ts):
- Change `tutorName`, `tuitionName`, `phone`, `whatsapp`, `address`, and `batches`.

### To customize Tier 2 (Pro Growth):
Edit [`src/data/tier2-data.ts`](file:///c:/Users/aryan/Classes-Template/src/data/tier2-data.ts):
- Change `name`, `teachers`, `batches`, and center contact details.

### To customize Tier 3 (Elite Academy):
Edit [`src/config/site.ts`](file:///c:/Users/aryan/Classes-Template/src/config/site.ts):
- Master white-label configuration for the full multi-page system.
